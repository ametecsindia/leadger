1. Introduction

Click2Call lets a user of a web application call a customer with one click, using the agent's own phone (mobile or desk phone) – not a softphone in the browser. When the agent clicks Click2Call:

  1. The application asks the calling provider to start a call.
  2. The provider rings the agent's phone first (the A party).
  3. When the agent answers, the provider dials the customer (the B party) and bridges the two calls.
  4. The customer sees the company's virtual number (VMN, the DID) as the caller ID, not the agent's private number.
  5. After the call, the provider reports the result (answered, busy, no answer...) and a recording URL; the application stores both.

This guide documents exactly how LeadGER implements this, then shows how to build the same thing in another Laravel (or any web) project.

Scope. This guide covers Click2Call only. LeadGER also has WebRTC (browser) calling; it is mentioned only where it shares code with Click2Call (the call-matching lookup and the recordings table).

4.3 Manual Dial vs Campaign calls

Both tabs use the same route POST /admin/dialer/click2call. The request field source decides where the call is stored (DialerController.php:328-353):

  • source=manual → row in dialer_logs (call_source='manual'). If the number exactly matches a lead's phonenumber/phonenumber_2, the lead is linked.
  • source=campaign (with lead_id, campaign_id) → row in call_logs (call_source='campaign').

6. Backend Integration

6.1 What LeadGER does in click2call (Confirmed, in order)

  1. Validate mobile (required, digits only, 10–20) and vmn (required). Errors → 422.
  2. Authenticated user, else 401.
  3. Permission: $user->canClick2Call() = users.c2c_channel == 1 and an agent number exists. Else 403 "Click2Call is not enabled for your account…".
  4. Calling rules: CallingRestrictionService::canPlaceOutboundCall() – calling hours (settings.calling_hours_from/to, default 09:30–19:30, company timezone) and per-number daily limit (settings.daily_call_limit, default 100). Blocked attempts are written to blocked_call_logs.
  5. Per-agent lock: Cache::lock("click2call_agent_lock_{userId}", 6); a second click within the lock → 429 "Another call is currently being processed…".
  6. License: crm_id from the encrypted settings.full_response (LeadGER-specific).
  7. VMN check: VmnService::check($user, $vmn, 'click2call', $pool) – the number must be configured for Click2Call, belong to one of the user's teams (Admin: any), and not be expired.
  8. Normalise numbers: digits only; 12 digits starting with 91 → last 10.
  9. Create the call row (dialer_logs or call_logs) with call_state='initiated', vmn_used, reference_id, start_time; plus an audit row in click2call_logs.
  10. Call the provider (Helper::click2call). This re-checks the calling rules with reserve=true, which atomically counts the attempt in daily_phone_call_attempts; if the provider fails, the attempt is given back.
  11. Respond: provider failure → 400 with the message; success → JSON with id, uuid, reference_id, provider_call_id.

6.4 Service class: talking to the provider

Same request as LeadGER (did, a_party_no, b_party_no, ref_id, record flags), with a timeout, TLS verification and a 2xx check added:

<?php
namespace App\Services\Click2Call;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class Click2CallGateway
{
    /** Same normalisation as LeadGER: digits only, 91XXXXXXXXXX -> XXXXXXXXXX. */
    public static function normalize(?string $number): string
    {
        $n = preg_replace('/\D/', '', (string)$number);
        return (strlen($n) === 12 && str_starts_with($n, '91')) ? substr($n, 2) : $n;
    }

    /** @return array{ok: bool, provider_call_id: ?string, message: string, raw: mixed} */
    public function start(string $vmn, string $agent, string $customer, string $refId): array
    {
        try {
            $res = Http::timeout(config('click2call.timeout'))->acceptJson()
                ->post(config('click2call.start_url'), [
                    'did' => self::normalize($vmn),
                    'a_party_no' => self::normalize($agent),
                    'b_party_no' => self::normalize($customer),
                    'ref_id' => $refId,
                    'record' => 1, 'recording' => 1, 'record_call' => 1,
                ]);
        } catch (\Throwable $e) {
            Log::warning('[Click2Call] gateway unreachable', ['ref_id' => $refId, 'error' => $e->getMessage()]);
            return ['ok' => false, 'provider_call_id' => null, 'message' => 'The calling service could not be reached. Please try again.', 'raw' => null];
        }
        $body = $res->json();
        // LeadGER: not JSON, or an "error"/"errors" key = failure. Added here: the HTTP status must be 2xx.
        if (!$res->successful() || !is_array($body) || isset($body['error']) || isset($body['errors'])) {
            Log::warning('[Click2Call] start refused', ['ref_id' => $refId, 'http' => $res->status()]);
            return ['ok' => false, 'provider_call_id' => null, 'message' => 'The call could not be started.', 'raw' => $body];
        }
        $id = $body['call_id'] ?? $body['callId'] ?? $body['uuid'] ?? ($body['response']['call_id'] ?? $refId);
        return ['ok' => true, 'provider_call_id' => (string)$id, 'message' => 'Call initiated', 'raw' => $body];
    }

    /** CDR + recording for a call (LeadGER: click2call_data/{ref_id}/{vmn}, header Secret-Key). */
    public function callData(string $refId, string $vmn): ?array
    {
        try {
            $res = Http::timeout(5)->withHeaders(['Secret-Key' => config('click2call.gateway_secret')])
                ->get(rtrim(config('click2call.cdr_url'), '/') . '/' . rawurlencode($refId) . '/' . rawurlencode(self::normalize($vmn)));
        } catch (\Throwable $e) {
            return null;
        }
        $json = $res->json();
        if (!is_array($json) || (int)($json['status'] ?? 0) !== 200 || !isset($json['data'])) {
            return null;
        }
        $cdr = $json['data']['response'] ?? [];
        if (is_string($cdr)) {
            $cdr = json_decode($cdr, true) ?: [];
        }
        return ['cdr' => (array)$cdr, 'recording_url' => $json['data']['recording_url'] ?? ($cdr['RecordVoice'] ?? null)];
    }
}

class Click2CallController extends Controller
{
    public function start(Request $request, Click2CallGateway $gateway, CallingRules $rules)
    {
        $data = $request->validate([
            'mobile'  => ['required', 'regex:/^\+?[0-9 ]{10,20}$/'],
            'vmn'     => ['required', 'string', 'max:20'],
            'lead_id' => ['nullable', 'integer'],
        ]);
        $user = $request->user();

        // 1. the user may use Click2Call and has an agent number (LeadGER: c2c_channel + click_agent_number/mobile)
        abort_unless($user->c2c_enabled && $user->agent_number, 403, 'Click2Call is not enabled for your account.');

        // 2. the VMN belongs to this user / team, is enabled for Click2Call and not expired (LeadGER: VmnService::check)
        $vmn = Click2CallGateway::normalize($data['vmn']);
        abort_unless($user->allowedVmns()->contains($vmn), 422, 'This VMN is not available to you.');

        // 3. calling hours + daily attempts per customer number (LeadGER: CallingRestrictionService)
        $customer = Click2CallGateway::normalize($data['mobile']);
        if ($why = $rules->blockReason($customer)) {
            return response()->json(['success' => false, 'message' => $why], 422);
        }

        // 4. one call at a time per agent (LeadGER: Cache::lock(..., 6))
        $lock = Cache::lock('c2c-agent-' . $user->id, 10);
        if (!$lock->get()) {
            return response()->json(['success' => false, 'message' => 'Another call is being started. Please wait a moment.'], 429);
        }
        try {
            // 5. the call row first, with a unique ref_id the provider echoes back
            $call = C2cCall::create([
                'user_id' => $user->id, 'lead_id' => $data['lead_id'] ?? null,
                'customer_number' => $customer, 'agent_number' => Click2CallGateway::normalize($user->agent_number),
                'vmn' => $vmn, 'ref_id' => (string)Str::uuid(), 'status' => 'initiated', 'started_at' => now(),
            ]);
            $rules->countAttempt($customer);

            // 6. ask the provider
            $res = $gateway->start($vmn, $call->agent_number, $customer, $call->ref_id);
            if (!$res['ok']) {
                $call->update(['status' => 'failed', 'ended_at' => now(), 'error' => $res['message']]);
                $rules->releaseAttempt($customer);
                return response()->json(['success' => false, 'message' => $res['message']], 400);
            }
            $call->update(['provider_call_id' => $res['provider_call_id']]);

            // "initiated" only: whether anybody answered is known from the call record later
            return response()->json(['success' => true, 'message' => 'Call initiated successfully', 'id' => $call->id]);
        } finally {
            $lock->release();
        }
    }
}

6.6 Call status: shared result handling

LeadGER uses one function for the webhook, the live poll and the scheduler (processWebhook), so all three produce the same result. Do the same:

<?php
namespace App\Services\Click2Call;

use App\Jobs\DownloadC2cRecording;
use App\Models\C2cCall;
use Carbon\Carbon;

class CallResult
{
    /** Same rules as LeadGER's Helper::callStateFromDialStatus. */
    public static function state(?string $dialStatus): ?string
    {
        $s = preg_replace('/[^a-z]/', '', strtolower((string)$dialStatus));
        if ($s === '') return null;
        if (str_contains($s, 'busy')) return 'busy';
        foreach (['noanswer', 'unanswer', 'notanswered', 'missed'] as $k) if (str_contains($s, $k)) return 'no-answer';
        foreach (['fail', 'cancel', 'reject', 'congestion', 'chanunavail'] as $k) if (str_contains($s, $k)) return 'failed';
        foreach (['answer', 'connect', 'completed', 'success'] as $k) if (str_contains($s, $k)) return 'completed';
        return null;
    }

    /** Same rules as LeadGER's CallRecordingService::providerCallFacts. */
    public static function facts(array $p): array
    {
        $a = self::state($p['A_DIAL_STATUS'] ?? $p['a_dial_status'] ?? null);
        $b = self::state($p['B_DIAL_STATUS'] ?? $p['b_dial_status'] ?? null);
        $t = fn ($k) => !empty($p[$k]) ? Carbon::createFromFormat('dmYHis', $p[$k]) : null;
        $connected = $t('B_PARTY_CONNECTED_TIME');
        $bEnd = $t('B_PARTY_END_TIME');

        $outcome = $b ?? (($a && $a !== 'completed') ? 'failed' : ($connected ? 'completed' : null));
        $talk = ($connected && $bEnd) ? $bEnd->diffInSeconds($connected, true)
            : (int)($p['talk_duration'] ?? $p['billsec'] ?? ($b ? 0 : ($p['duration'] ?? 0)));
        if ($outcome !== 'completed') $talk = 0;

        $event = strtolower((string)($p['EVENT_TYPE'] ?? ''));
        $ended = str_contains($event, 'end') || str_contains($event, 'hangup') || $bEnd || !empty($p['A_PARTY_END_TIME'])
            || ($outcome && $outcome !== 'completed');

        return ['outcome' => $outcome, 'talk' => (int)$talk, 'ended' => (bool)$ended,
                'connected_at' => $connected, 'agent_answered' => $a === 'completed'];
    }

    /** Apply a provider record to the call (idempotent: the same record twice changes nothing). */
    public function apply(C2cCall $call, array $cdr, ?string $recordingUrl): void
    {
        $f = self::facts($cdr);
        $call->cdr = $cdr;
        if ($f['connected_at']) $call->answered_at = $f['connected_at'];
        if ($f['ended']) {
            $call->status = $f['outcome'] ?? 'failed';
            $call->ended_at = $call->ended_at ?? now();
            $call->talk_seconds = $f['talk'];
        } elseif ($f['agent_answered']) {
            $call->status = $f['connected_at'] ? 'connected' : 'ringing';
        }
        if ($recordingUrl && $f['outcome'] === 'completed' && !$call->recording_url) {
            $call->recording_url = $recordingUrl;
            $call->recording_status = 'pending';
            DownloadC2cRecording::dispatch($call->id);
        }
        $call->save();
    }
}

    {

        $p = $request->json()->all() ?: $request->all();
        $ref = $p['ref_id'] ?? $p['REF_ID'] ?? $p['reference_id'] ?? null;
        $providerId = $p['call_id'] ?? $p['CALL_ID'] ?? $p['uuid'] ?? null;

        // Match by our ref_id, then by the provider id. Never "latest call to this number" (LeadGER's last resort).
        $call = ($ref ? C2cCall::where('ref_id', $ref)->first() : null)
            ?? ($providerId ? C2cCall::where('provider_call_id', $providerId)->first() : null);
        if (!$call) {
            Log::info('[Click2Call] webhook for an unknown call', ['ref_id' => $ref]);   // no phone numbers in logs

        }

        $recording = $p['recording_url'] ?? $p['RecordVoice'] ?? $p['record_url'] ?? null;
        $result->apply($call, $p, $recording);
        return response()->json(['status' => 'success']);
    }
}

6.9 Recording download job and sweep

<?php
namespace App\Jobs;

use App\Models\C2cCall;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Storage;

class DownloadC2cRecording implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public $tries = 5;
    public $backoff = [5, 15, 30, 60, 120];   // same as LeadGER's DownloadRecordingJob

    public function __construct(public int $callId) {}

    public function handle(): void
    {
        $call = C2cCall::find($this->callId);
        if (!$call || !$call->recording_url || $call->recording_status === 'completed') return;

        $res = Http::timeout(60)->connectTimeout(15)->get($call->recording_url);
        if (!$res->successful() || $res->body() === '') {
            throw new \RuntimeException('Recording not available yet (HTTP ' . $res->status() . ')');   // retried
        }
        $ext = pathinfo(parse_url($call->recording_url, PHP_URL_PATH) ?? '', PATHINFO_EXTENSION) ?: 'wav';
        $path = 'recordings/' . $call->started_at->format('Ymd_His') . '_' . $call->id . '.' . strtolower($ext);
        Storage::disk(config('filesystems.default'))->put($path, $res->body());   // a PRIVATE disk
        $call->update(['recording_path' => $path, 'recording_status' => 'completed']);
    }

    public function failed(\Throwable $e): void
    {
        C2cCall::whereKey($this->callId)->update(['recording_status' => 'failed']);
    }
}

    } catch (e) {
      show('error', e.message);
      busy = false; btn.disabled = false;
    }
  });

  function poll(id) {
    let inFlight = false;
    pollTimer = setInterval(async () => {
      if (inFlight) return;
      if (Date.now() - startedAt > 15 * 60 * 1000) { stop('error', 'Call result not available'); return; }
      inFlight = true;
      try {
        const r = await fetch('/calls/' + id + '/status', { headers: { 'Accept': 'application/json' } });

        const [kind, text] = STATES[s.status] || ['calling', 'Calling...'];

        else show(kind, s.status === 'connected' && s.connected_for != null ? text + ' ' + fmt(s.connected_for) : text);
      } catch (e) { /* temporary network problem: try again on the next tick */ }
      inFlight = false;
    }, 2000);   // LeadGER polls every 2 s
  }

  function stop(kind, text) {
    clearInterval(pollTimer);
    show(kind, text);
    busy = false; btn.disabled = digits().length < 10;
  }
  const fmt = (s) => String(Math.floor(s / 60)).padStart(2, '0') + ':' + String(s % 60).padStart(2, '0');
})();

9.1 Dial status → state (Confirmed: Helper::callStateFromDialStatus, Helper.php:159-168)

The provider's status text is lower-cased and reduced to letters, then:

9.2 Call result (Confirmed: CallRecordingService::providerCallFacts, :318-368)

  • Outcome = the customer leg (B_DIAL_STATUS) when present. Without it: if the agent leg (A_DIAL_STATUS) exists and did not answer → failed ("your phone did not answer, the customer was not dialled"); else if B_PARTY_CONNECTED_TIME is set → completed.
  • Talk time = B_PARTY_END_TIME − B_PARTY_CONNECTED_TIME, else talk_duration, else billsec, else duration (only when there is no B status). Forced to 0 when the outcome is not completed.
  • Ended when EVENT_TYPE contains end/hangup, or a B/A end time exists, or the outcome is final and not completed.

  • ref_id = {Str::uuid}_d_{crm_id}_{user_id}_1, stored in reference_id (UNIQUE in both call tables) and sent to the provider.
  • provider_call_id starts as the ref_id and is replaced by the provider's id if the start response contains one.
  • Incoming events are matched (CallRecordingService::findCallRecord) by ref_id, then the provider id, then the uuid prefix, and as a last resort the latest call to the same number in the last 24 h. Do not copy the last resort: with two calls to the same number it can attach a result to the wrong call.

9.5 Three ways the status arrives

  1. Webhook from the provider when the call ends (5.3) – fastest for the final result.
  2. Live poll: every 2 s the browser asks LeadGER; while the call is live and no final record is stored, LeadGER fetches click2call_data (3 s timeout). This is what drives Ringing / Connected on screen.
  3. Scheduler sweep every minute / 5 minutes: catches calls whose webhook never arrived.

All three apply the record through the same function, so the result is the same whichever arrives first (idempotent).

10. Call Recording Integration

  1. The start request asks for recording (record, recording, record_call = 1).
  2. The recording URL arrives in the webhook (recording_url, RecordVoice, ...) or from click2call_data (data.recording_url).
  3. Only connected calls with talk time get a recording row (busy / unanswered / failed calls are ignored, processWebhook).
  4. One recordings row per call, linked both ways: recordings.dialer_log_id / call_log_id and dialer_logs.recording_id / call_logs.recording_id. A unique provider_call_id prevents duplicates.
  5. DownloadRecordingJob (queue): 5 tries with back-off 5, 15, 30, 60, 120 s; 60 s timeout; saves to storage/app/recordings/{Ymd_His}_{recording id}_{phone digits}.{ext}; marks completed or failed.
  6. If no URL arrives, the scheduler asks again; after 60 minutes the row becomes unavailable.
  7. Playback: /admin/reports/download-recordings/{id}/{source}, streamed with HTTP Range when ?play=1. Telecallers / Sales Persons only for their own calls (or their leads); other roles all. If the file is not local, LeadGER redirects to the provider URL.
Recommended for your project: keep recordings on a private disk and serve them only through an authorised route (never a public URL); do not redirect users to the provider's raw recording URL.

11. Security and Authentication

11.1 What LeadGER does (Confirmed)

  • Calls can only be started by logged-in users with Click2Call enabled and an agent number, from a VMN of their team that is not expired, within calling hours and under the daily per-number limit.
  • Per-agent lock (6 s) against double clicks.
  • Provider calls are made only from the backend; the browser never sees provider URLs or secrets.
  • CSRF on all dashboard routes; the webhook is CSRF-exempt and rate-limited (60/min).
  • Recording access is role-checked.

11.3 Checklist for your project

  • Credentials: in .env, never in code or the frontend; separate secrets for the gateway and the webhook.
  • Backend-only provider calls: the browser talks only to your backend.
  • Authorization: who may call, from which VMN, and who may see which call / recording.
  • Phone validation: digits (optionally a leading +), normalise once, 10 digits for India; reject anything else.
  • Rate limiting: throttle on the start route, a per-agent lock, and a per-number daily cap.
  • Webhook: required secret or signature, IP allow-list if the provider publishes IPs, idempotent processing, HTTP 200 for unknown calls (so the provider does not retry forever).
  • Duplicates: unique ref_id; disable the button while a call starts; the lock on the server.
  • Recordings: private storage, authorised streaming route, no public links.
  • Logs: no secrets, no full phone numbers, no recording URLs.

12. How to Integrate LeadGER Click2Call into Another Project

Follow these steps in order. Each step can be tested before moving on.

Step 1 – Provider account

  • Get from your provider: access to the start-call API (LeadGER uses Telozar c2c_call), access to the call-data API (LeadGER uses the Ametecs gateway click2call_data) and its Secret-Key, and at least one VMN enabled for Click2Call.
  • Ask how the start API authenticates you (LeadGER sends no credentials – most likely your server IP is allow-listed). Give them your server's public IP if needed.
  • Give them your webhook URL (e.g. https://your-app.example.com/api/click2call/webhook) and agree on a webhook secret header.
  • Ask for a sample start response and a sample webhook / CDR payload. Check that they contain ref_id, A_DIAL_STATUS, B_DIAL_STATUS, B_PARTY_CONNECTED_TIME, B_PARTY_END_TIME and a recording URL, as used in this guide.

Step 2 – Configuration

Add the .env values and config/click2call.php from 6.2. Set QUEUE_CONNECTION=database and run php artisan queue:table && php artisan migrate if the jobs table does not exist.

Step 3 – Database

Create the migration from 8.2, run php artisan migrate, insert your VMN(s) into vmns. Add to users: c2c_enabled (boolean) and agent_number (the agent's phone). Create the C2cCall model with $casts = ['cdr' => 'array', 'started_at' => 'datetime', 'answered_at' => 'datetime', 'ended_at' => 'datetime'].

Step 4 – Gateway service

Add Click2CallGateway (6.4). Test it alone in php artisan tinker with your own two phones as agent and customer:

app(\App\Services\Click2Call\Click2CallGateway::class)
    ->start('<YOUR_VMN>', '<YOUR_PHONE>', '<SECOND_PHONE>', (string)\Illuminate\Support\Str::uuid());

Your phone should ring; answer it and the second phone should ring with the VMN as caller ID.

Step 5 – Calling rules

Add a small CallingRules service: blockReason($phone) returns a message outside calling hours (company timezone) or when today's attempts for the number reached the limit; countAttempt / releaseAttempt increment / decrement c2c_daily_attempts atomically (INSERT ... ON DUPLICATE KEY UPDATE).

Step 6 – Start route and controller

Add the routes (6.3) and Click2CallController::start (6.5). Test with the browser or Postman (logged in): the response must be {"success":true,"id":...} and a c2c_calls row with status=initiated.

Step 7 – Status handling

Add CallResult (6.6), the webhook controller (6.7) and the status endpoint (6.8). Exclude the webhook from CSRF (it is under api/, which has no CSRF by default). Test the webhook with curl (13.1).

Step 8 – Recordings

Add DownloadC2cRecording (6.9), start a worker (php artisan queue:work, under Supervisor in production) and the scheduler cron (* * * * * php artisan schedule:run). Add a sweep command that, every few minutes, calls callData() for calls that are still live or still waiting for a recording, and marks them unavailable after 60 minutes. Add an authorised route that streams recording_path.

Step 9 – Frontend

Add the HTML and JavaScript from 7.2 / 7.3 to your page. Pass the user's allowed VMNs to the view.

Step 10 – First test call

  1. Log in as a user with c2c_enabled=1 and an agent_number.
  2. Enter a test customer number (a second phone you own), pick the VMN, click Click2Call.
  3. Your phone rings → answer → the UI shows Ringing; the customer phone rings with the VMN → answer → Connected with a timer.
  4. Hang up → within seconds Ended with the talk time; the row has status=completed, talk_seconds, cdr.
  5. Within a few minutes recording_status=completed and the recording plays.
